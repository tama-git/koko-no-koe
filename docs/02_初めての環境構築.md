# 初めての環境構築：Windows・iPhone・管理者画面

この資料は、何も用意していないメンバーがGitHubのソースを取得するための手順です。iPhoneだけでは開発サーバーを動かせないため、各自のWindows PCを使います。

## 1．準備するもの

| もの | 用途 |
| --- | --- |
| Visual Studio Code | ファイルの編集とターミナルの利用 |
| Git | GitHubのコードの取得と共有 |
| Node.js 24系のLTS版 | ExpoをPCで動かす。24.3.0以上を使用 |
| Python 3.13 | DjangoをPCで動かす |
| GitHubアカウント | チームの変更を共有する |
| Expoアカウント・iPhoneのExpo Go | 各自のiPhoneでアプリを開く |

Expo、GitHub、将来のここの声の利用者・管理者アカウントは別です。Expoで自分のユーザー名が表示されても、ここの声の認証を作ったことにはなりません。

## 2．PCのツールをインストールする

すでに入っているものは入れ直しません。

1. [VS Code公式](https://code.visualstudio.com/) からWindows版をインストールする。
2. [Git公式](https://git-scm.com/install/windows) からGit for Windowsをインストールする。一般的なIntel・AMDのWindows PCは「x64 Setup」。PATHの選択では「Git from the command line and also from 3rd-party software」を使う。
3. [Node.js公式](https://nodejs.org/ja/download) から24系のLTS版を入れる。Node.jsと一緒にnpm・npxも入る。
4. [Python公式のWindows配布一覧](https://www.python.org/downloads/windows/) からPython 3.13の通常のインストーラーを入れる。一般的なIntel・AMDのPCは「Windows installer (64-bit)」。embeddable packageは使わない。インストーラーに「Add python.exe to PATH」があればチェックし、Python Launcherもインストールする。
5. インストール後、VS CodeとPowerShellをすべて閉じて開き直す。

ARM版Windowsの場合は、PCのシステム情報に合わせたARM64のインストーラーを使います。判断できない場合はシステム情報を担当者に確認してください。

## 3．ターミナルで準備を確認する

VS Codeで「ターミナル」→「新しいターミナル」を選びます。先頭が `PS` のPowerShellを使います。画面の `PS C:\...>` は入力せず、下のコマンドだけを1行ずつ実行します。

```powershell
git --version
```

```powershell
node --version
```

```powershell
npm.cmd --version
```

```powershell
py -3.13 --version
```

すべてバージョン番号が表示されれば次へ進みます。Node.jsは24系の24.3.0以上、Pythonは3.13系をチームの準備基準とします。`git` が認識されない場合はVS Codeを開き直し、それでも同じならGitのインストールとPATHを確認します。

## 4．GitHubとExpoを準備する

GitHubで変更を共有する人は、リポジトリ所有者からの招待を受けて承認します。リポジトリは公開ですが、変更を送るには権限が必要です。各自、自分のGitHubアカウントを使ってください。

iPhoneではApp Storeから「Expo Go」をインストールし、自分のExpoアカウントでログインします。ローカルネットワークへのアクセスを許可し、開発時はPCと同じWi-Fiに接続します。ほかの人のパスワードやアクセストークンは使いません。

## 5．GitHubからソースを取得する

まず保存先の親フォルダーを作ります。`$env:USERPROFILE` は、自分のWindowsユーザーのフォルダーを指します。文字を置き換えず、そのまま入力できます。

```powershell
New-Item -ItemType Directory -Path "$env:USERPROFILE\Documents\TabinikkiDev" -Force
```

```powershell
Set-Location "$env:USERPROFILE\Documents\TabinikkiDev"
```

```powershell
git clone https://github.com/tama-git/koko-no-koe.git
```

```powershell
Set-Location .\koko-no-koe
```

```powershell
code .
```

`code` と `.` の間には半角スペースがあります。VS Codeの左側に `mobile`、`admin`、`docs` が表示されれば正しい場所です。フォルダーの作成者を信頼できる場合だけ、VS Codeの信頼確認を承認します。

すでに `koko-no-koe` があるというエラーになったら、削除・再cloneせず、既存の場所と中身を確認します。`code .` でユーザーのフォルダーが丸ごと開いた場合は、アプリのフォルダーに移動できていません。

## 6．アプリと管理者画面を起動する

ここまでできたら、[01_チームの起動手順](01_チームの起動手順.md) の「3．ターミナル①」から進めてください。取得直後は最新版なので、「2．GitHubから新しい構成を取得する」を繰り返す必要はありません。

成功の目安は次の2つです。

- iPhoneで「ここの声」のログイン画面が開く。会員登録・ログインのサーバー接続は準備中です。
- PCのブラウザーで「管理者用の仮ページ」が開き、サンプル通報の絞り込みと詳細の表示ができる。
