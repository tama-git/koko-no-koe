# 地図機能の担当場所（準備用）

`screens/MapScreen.tsx` は地図・投稿一覧の画面雛形です。地図や投稿一覧の取得・表示は未実装です。必要に応じて `components/` や `api.ts` を追加します。トップ画面は `../home/screens/HomeScreen.tsx` にあります。

地図ライブラリ、現在地の取得・許可・取得失敗の表示、閲覧距離の仕様を確認してから実装してください。距離の判定は画面だけでなくサーバー側でも必要です。`App.tsx` の画面切り替えやトップへの組み込みは担当者と調整します。

手順は [画面と機能の分担ガイド](../../../../docs/04_画面と機能の分担ガイド.md) を参照してください。
