# 位置情報の担当場所

トップ画面では `expo-location` でアプリ利用中の許可を確認します。初回取得後はアプリが前面にある間だけ現在地を更新し、半径250mの表示と投稿一覧に反映します。

- `getCurrentLocation.ts`：端末の位置情報APIとの接続。同時に要求された場合は許可確認を共有します。
- `locationRequest.ts`：許可拒否・位置情報オフ・取得失敗・タイムアウトを区別します。自動テストでは端末APIを差し替えます。
- `useCurrentLocation.ts`：初回の取得結果と歩行中の座標を画面に渡します。バックグラウンド移行時や画面を閉じたときに購読を解除します。

許可ダイアログの回答待ちは時間制限しません。許可後は取得の待ち時間を15秒に制限し、結果が届かなければ案内を表示して地図の操作を継続します。端末の単発取得自体は途中キャンセルできないため、遅れて届いた結果は表示に使いません。

初回の取得は `Balanced`、歩行中の更新は `High` を使用します。位置情報の誤差により、250m付近では表示が切り替わることがあります。距離の判定はトップ画面で使用します。
