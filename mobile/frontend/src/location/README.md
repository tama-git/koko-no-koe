# 位置情報の担当場所

Phase 2では `expo-location` でアプリ利用中の許可を確認し、現在地を一度取得します。バックグラウンドの許可・追跡、位置の保存やDjangoへの送信は行いません。

- `getCurrentLocation.ts`：端末の位置情報APIとの接続。同時に要求された場合は許可確認を共有します。
- `locationRequest.ts`：許可拒否・位置情報オフ・取得失敗・タイムアウトを区別します。自動テストでは端末APIを差し替えます。
- `useCurrentLocation.ts`：取得中と取得結果を画面に渡します。画面を閉じた後の取得結果は反映しません。

許可ダイアログの回答待ちは時間制限しません。許可後は取得の待ち時間を15秒に制限し、結果が届かなければ案内を表示して地図の操作を継続します。端末の単発取得自体は途中キャンセルできないため、遅れて届いた結果は表示に使いません。

位置取得は `Balanced` 精度を使用します。返された位置は必ずしも正確ではなく、今回は地図を中心へ移動する用途だけです。投稿可否や圏内判定の根拠には使用していません。

現在地への再移動ボタン、領域の保存、継続的な移動追従は次のフェーズ以降です。閲覧可否や距離は今後サーバー側でも確認する必要があります。
