# 会員登録・ログイン画面の開発メモ

現在は画面と入力チェックを作成しています。会員登録・ログインAPIは管理者側の担当者が作成中で、接続先や応答の形式は未定です。

## 今できる確認

- ログイン画面と会員登録画面の切り替え
- メールアドレスとパスワードの未入力チェック
- 会員登録時のパスワード条件：8文字以上、英大文字・英小文字・数字・記号の4種類中3種類以上
- 確認用パスワードの一致チェック

まだ実際の登録・ログインはできません。条件を満たしてボタンを押すと、接続が準備中であることを表示します。確認の際はサンプルの値を使ってください。

本人確認メールは今回は省略します。パスワードのハッシュ化と照合はバックエンドで行い、入力条件もサーバー側で再確認します。確認用パスワードは保存しません。

## 接続前に担当者と決めること

以下は確認項目であり、APIの確定仕様ではありません。

1. 会員登録とログインのURL・HTTPメソッド
2. 送信する項目と、成功・失敗時に返す情報
3. ログイン状態を保持する方法、有効期限、ログアウトの方法
4. 登録直後にログインするか、ログイン画面に戻るか
5. モバイルと管理者が使用する会員データの共有方法
6. iPhoneから開発中のサーバーに接続する方法

サーバー接続後は、不正な入力、登録済みメールアドレス、認証失敗、通信できない場合、成功後の画面遷移を実機で確認します。
