# 投稿機能の担当場所（準備用）

`screens/` に投稿作成・公開前確認・投稿詳細の画面雛形があります。投稿一覧は地図と同じ画面に表示する予定のため `../map/screens/MapScreen.tsx` を参照してください。データの取得・保存・画面遷移は未実装です。必要な部品や通信ファイルは仕様を確認して追加します。

送信項目、画像の扱い、公開範囲、閲覧権限、匿名表示、削除の仕様を確認してください。APIがない間は仮データであることを明示します。保存に成功していないのに完了扱いにする処理は追加しません。

手順は [画面と機能の分担ガイド](../../../../docs/04_画面と機能の分担ガイド.md) を参照してください。
