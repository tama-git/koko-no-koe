投稿機能モジュール

現在はモバイルのBearer認証を使用し、投稿の保存後に既存詳細画面で確認できます。トップの一覧は「自分の投稿」です。代表PCの投稿テーブルは作成済みです。実装内容・テスト・未対応事項は [投稿保存と確認](../../../../docs/08_投稿保存と確認.md) を参照してください。
 
このディレクトリには、マルチステップの投稿作成フロー（作成・確認・完了）および投稿詳細表示に必要な画面とAPI通信処理が実装されています。
 
構成ファイル一覧
 
1. PostCreateScreen.tsx（投稿作成画面）
 
役割: ユーザーからのテキスト入力、カメラを使った写真撮影、GPSによる現在地（緯度・経度）の取得を行います。
 
特徴:
 
expo-image-picker を使用してその場でカメラを起動・撮影します。
 
expo-location を使用して現在地の座標を取得します。
 
取得したデータをナビゲーション経由で PostConfirmScreen へ受け渡します。
 
2. PostConfirmScreen.tsx（投稿確認・最終送信画面）
 
役割: PostCreateScreen から受け取った入力内容（メッセージ・画像・位置情報・公開設定）を送信前にプレビュー表示し、バックエンドへ最終送信します。
 
特徴:
 
送信前にユーザーが内容を確認・修正できるステップを提供します。
 
「この内容で投稿する」を押すことで postService.ts の API を呼び出します。
 
3. PostDetailScreen.tsx（投稿詳細画面）
 
役割: 選択された特定の投稿IDに基づき、詳細データ（本文、撮影写真、位置情報、日時等）を取得して表示します。
 
特徴:
 
画面読み込み時に getPostById を呼び出し、サーバーから最新データを取得します。
 
4. postService.ts（API通信モジュール）
 
役割: Django バックエンドサーバーとの HTTP 通信（GET / POST）を一手に引き受けるサービス層です。
 
主な関数:
 
loadPosts(): 投稿一覧の取得 (GET)
 
createPost(postData): 新規投稿の登録 (POST / FormData対応)
 
getPostById(postId): 特定投稿の詳細取得 (GET)
 
 投稿フローの流れ
 
入力・撮影: PostCreateScreen で写真・メッセージ・位置情報をセットして確認画面へ。
 
プレビュー確認: PostConfirmScreen で内容を確認し、問題がなければ送信。
 
サーバー連携: postService.ts 経由で Django バックエンドへ FormData 形式で POST。
 
詳細表示: タイムライン等から各投稿をタップすると PostDetailScreen で詳細データを確認。
