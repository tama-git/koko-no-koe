# モバイルの通報機能

他の会員の公開投稿を詳細で開き、「…」→「通報」を選びます。理由は1カテゴリを選択し、自由記述は100文字までです。「その他」の場合は入力が必要です。送信と入力破棄は確認アラートで確定します。「非表示」はメニュー上の準備中項目です。

`screens/ReportScreen.tsx` がフォーム、`reportService.ts` がAPIへの送信を担当します。`POST /api/posts/<id>/reports/` は既存の会員トークンを使い、`category` と `details` を受け付けます。成功は201、同じ会員からの重複は409です。保存時に対象投稿を「要確認」にします。現在の閲覧範囲に合わせ、通報時の距離制限は未接続です。

通報機能を使うDjangoのDBには `posts.0002_post_reports` の適用が必要です。管理者向けの一覧では、後から投稿にひも付く `PostReport` と `Post.report_status` を利用できます。

手順は [画面と機能の分担ガイド](../../../../docs/04_画面と機能の分担ガイド.md) を参照してください。
